# Changelog

## 0.1.0

Initial experimental release.

- Embedded Agent Runtime via `aifluxon-api`
- Public OpenAI-compatible providers (OpenAI, DeepSeek, Qwen, Kimi, Gemini, Codex, Custom)
- Persistent sessions, async events, Python tools, generic ToolPolicy, operations/approval
- Python SDK for Windows x86_64, CPython 3.11–3.14
- ChatGPT Web and DeepSeek Web are not part of the public Python SDK
