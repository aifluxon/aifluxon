# Provider preservation matrix

This matrix is the A7 source of truth. A checked row is backed by an automated local test and does not authorize deletion of the EasyPhy implementation until the equivalent provider-owned path is active.

| Provider | Preserved behavior | Current executable evidence | Migration owner |
|---|---|---|---|
| OpenAI | Responses/Chat routing, model reasoning normalization, deterministic prompt cache key, tools and usage | `ai::tests::openai_request_uses_prompt_cache_key_without_stateful_fields`, `reasoning_effort_is_normalized_to_real_model_levels`, `openai_responses_sends_nested_reasoning_when_configured`, `aifluxon_providers::openai::tools::tests` | `aifluxon-providers/openai` + `openai_compatible` |
| DeepSeek API | thinking toggle, effort normalization, v4-flash Responses routing, native search shape, reasoning/canonical replay and duplicate suppression | `ai::tests::deepseek_responses_is_limited_to_v4_flash_and_maps_reasoning`, `deepseek_v4_disabled_sends_explicit_thinking_disabled`, `deepseek_responses_web_search_uses_native_minimal_tool_shape`, `deepseek_responses_restores_persisted_reasoning_as_plaintext_input`, canonical replay tests | `aifluxon-providers/deepseek` |
| Qwen | thinking mode/budget, explicit and Responses caches, image limits, document/file-extract behavior, tool stream, summary-only continuation | Qwen normalization/thinking/cache/image/document tests in `ai::tests`; summary/delta tests in `agent_stream::tests`; `qwen_summary_only_turn_requests_continuation` / `qwen_normal_final_answer_does_not_continue` in `aifluxon-providers` | `aifluxon-providers/qwen` + `openai_compatible` |
| Kimi | official endpoint normalization, stable logical-session cache identity, reasoning replay and thinking tags | `ai::tests::official_kimi_profile_is_normalized_to_dedicated_provider`, `kimi_prompt_cache_key_is_stable_per_session_and_isolated_between_sessions`, K2.6/K2.7 and history tests; `agent_stream` think-tag tests | `aifluxon-providers/kimi` |
| Gemini | capability/routing, native search, 6-message/12,000-character search shaping | Gemini reasoning/search tests in `ai::tests` | `aifluxon-providers/gemini` |
| Codex | official Responses endpoint, account credential input, session/turn-state continuation, encrypted reasoning, hosted tools, non-terminal `end_turn` mapped to generic Continue | Codex contract/session/account tests in `ai::tests`; `codex_non_terminal_end_turn_requests_continuation` / `codex_terminal_end_turn_stops` in `aifluxon-providers` | protocol in `aifluxon-providers/codex`; auth/keyring remain EasyPhy |
| Custom | arbitrary base URL/model, Chat Completions or Responses, portable defaults, cumulative-delta compatibility | `ai::tests::custom_provider_honors_explicit_responses_mode`, provider-test routing; `agent_stream::tests::custom_provider_cumulative_deltas_only_append_the_missing_suffix` | `aifluxon-providers/custom` |
| ChatGPT Web | private hosted-agent boundary, conversation cursor/state, hosted/local tool separation, reasoning/search continuity | ChatGPT Web conversation, state isolation, local tool protocol, SSE and hosted activity tests | EasyPhy private adapter implementing generic `ModelProvider` |
| DeepSeek Web | private SSE, session-scoped persistent binding, persistence generation, cache-loss recovery, local tool boundary | DeepSeek Web session/binding/restart/tombstone/SSE tests | EasyPhy private adapter implementing generic `ModelProvider` |
| Common HTTP | HTTP/1, 30s connect/180s read/90s idle, retry at most three attempts, clone/transient gating, redaction and bounded diagnostics | A7 common transport unit tests plus current EasyPhy integration tests | `aifluxon-providers/common/http` |

Provider cache and continuation identity always follow logical `SessionId`/`ProviderSessionKey`; changing `RunId` must not reset them.
